# Brand assets (Home Assistant–style names)

Canonical files for [home-assistant/brands](https://github.com/home-assistant/brands): `icon.png`, `logo.png`, optional `dark_icon.png`, `dark_logo.png`, and `@2x` variants.

| File | Notes |
|------|--------|
| `dark256x256.png` | Source for **`dark_icon.png`** (same image; dark background). |
| `light256x256.png` | Source for **`icon@2x.png`** (256×256 light artwork). |
| `logo256x256.png` | Same pixels as `light256x256.png`; copied to **`logo@2x.png`**. |
| `open-m2m-logo.png` | Same image as **`icon.png`** / **`logo.png`** (duplicate filename from repo root). |
| `open-m2m-logo-s.png` | Alternate 225×225 asset; not mapped to a fixed HA filename—keep if you use it elsewhere. |
